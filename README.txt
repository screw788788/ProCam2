Build the APK without Android Studio (GitHub Actions)
1. Make a free account at github.com and create a new repository (name: ProCam).
2. Click "uploading an existing file" and drag in EVERYTHING from this folder
   (including the hidden .github folder - upload by dragging the folders, not by selecting files).
3. Commit. Go to the Actions tab, open the "Build APK" run, wait ~5 minutes.
4. Scroll to Artifacts, download ProCam-apk, unzip it, copy app-debug.apk to your phone.
5. Tap it and allow "install unknown apps".
